# IIT Hackathon Presentation Guide

## Five-minute flow

1. Open `/demo` and run the credential-free demonstration.
2. Show the score, confidence, security, and research readiness signals.
3. Open `/executive` for the judge-facing summary.
4. Open `/knowledge` to show graph entities, evidence, and RAG citations.
5. Open `/dashboard` to show the live verification command center.
6. Open `/performance` to show cache, queue, worker, latency, and resource signals.
7. Explain the architecture: existing services remain the source of truth, while providers and deployment targets are ports.
8. Finish with PDF/PPTX/Markdown/JSON/CSV export options.

## Key message

ReproProof turns reproducibility review from a manual debugging task into an evidence-backed, explainable, multi-agent workflow.

## Demo fallback

The demo mode is deterministic and does not need credentials, an uploaded repository, or external services. For a live repository, use the normal upload flow and then the existing dashboard.
