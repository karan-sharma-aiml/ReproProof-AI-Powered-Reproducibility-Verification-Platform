# Demo Guide

1. Start the backend and frontend using the existing development instructions.
2. Open `/demo`.
3. Click `Run demo`.
4. Open `/executive` for the scorecard.
5. Open `/knowledge` for graph and RAG inspection.
6. Open `/performance` for operational signals.
7. Use `/dashboard` for the full upload and verification workflow.

The demo uses deterministic sample data and does not require credentials.
