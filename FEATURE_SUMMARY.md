# Feature Summary

## Core verification

Upload repositories, inspect structure and dependencies, execute through safe boundaries, compare metrics, diagnose failures, generate repairs, retry, rollback, and export reports.

## Intelligence

Research intelligence, paper parsing, dataset quality, explainable judge scores, confidence, recommendations, knowledge graph indexing, semantic/RAG retrieval, citations, and source attribution.

## Agents

Repository, research paper, dataset, execution, security, repair, reviewer, and judge agents with shared context, memory, events, retries, timeouts, workflow templates, pause/resume/cancel, and human actions.

## Enterprise operations

Provider manager and AI gateway, security headers/RBAC primitives, request IDs, health, metrics, tracing, cache, workers, benchmarks, circuit breakers, deployment profiles, Kubernetes manifests, Docker artifacts, and CI/CD contracts.

## Demo surfaces

Dashboard, analytics, troubleshooting, reports, knowledge explorer, performance dashboard, judge demo mode, executive view, PDF/PPTX/Markdown/JSON/CSV outputs.
